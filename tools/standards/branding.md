# 作者品牌规范 · 1.0

作者于2026-09-26确认：所有图书与独立教程共用本人的彩色圆头像，PDF也使用彩色，不制作或采用灰度版。

## 素材

`assets/branding/mali-avatar-v1.svg` 内嵌作者提供的原始照片，通过圆形裁切边界显示。照片字节、五官、构图和色彩不重绘；圆外透明。它是实际照片的显示封装，不是生成式人像。原始照片母版留总控；书仓内嵌资源可离线使用。

作者头像属于品牌资产，不属于 FIG 教学插图，不参与 notebook-pen-v1 的灰度、纸底和不透明性检查。教学插图维持原有规范，头像始终保留彩色；这一例外适用于README、封面、PDF和多语言版。

`book.yaml.branding` 登记 `name`、可选 `name_en`、`avatar`、`sha256`；校验素材存在、书内相对路径和版本摘要。总控、两种模板及已启动作品使用相同素材快照。更新头像使用新版本并更新摘要，不覆盖历史发行文件。

## 使用

- 首页在标题与读者价值附近放48px头像和作者名。合订阅读稿由构建器自动加入署名。英文使用同一头像和 `name_en`，不在照片上写字。
- PDF封面署名头像标准版22mm，窄版16mm；正文页眉左侧8mm彩色头像和姓名，右侧书名，页脚为页码。封面、版本来源页和目录不叠加正文页眉。
- 页眉与正文分开：带头像时标准版正文上边距20mm，窄版18mm；标准版每页8mm头像。实际导出须目视核对标题、头像、正文之间的距离及长书名换行。
- 书末作者介绍可使用较大头像，真实简介和已验证链接按作品需要加入；不编造履历或作者主页。宣传封面后续修订可加入小彩色头像，不因本机制自动重生成或上传分享图。
- 正文教学图、代码和背景不添加头像水印。保持阅读入口和内容为主要视觉层级。

## 生成与验证

普通build不会导出PDF，也不会调用图像服务。PDF头像从指定正文提交的书内资产取得，摘要进入导出回执，不从总控或用户照片库偷取最新文件；旧来源没有branding字段时保持原版行为。

新的PDF页眉模板仍须实际排版、渲染和检查。静态检查通过不等于已验收整书、手机阅读器或所有语言版。正式PDF遵守随书PDF流程；历史PDF保持原样。
