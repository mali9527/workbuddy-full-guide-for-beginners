# PDF 电子书规范 · 1.1

生效日期：2026-09-26。适用于本系列图书、独立教程及其本地 PDF 导出。生成主线为 Markdown → Pandoc → Typst；正文来源、排版工具和交付文件分别登记。具体命令见总控或随书的 `tools/PDF.md`，程序字段以 `tools/FORMAT.md` 为准。

## 导出范围

只有作者明确要求 PDF 时才导出。一次导出明确作品、固定正文提交 C、正文版本、导出号和阅读配置；默认仅交付本地文件。普通构建、状态检查和推送不自动生成 PDF，不自动把 PDF 设为推荐版。

本版 PDF 接口仅处理作品的主语言，不将已启用翻译等同于可导出翻译 PDF。目标语言接通前，不绕过接口拼接译文，也不以中文图替代缺失的目标语图。标准版通过不代表手机版或另一语言通过。

正文、章节顺序和采用图片从 C 的干净快照取得，章节唯一清单为 `book.yaml.units`。缺章、缺图、无效链接或来源检查失败时停止；不得跳过材料继续生成。工作区未提交正文不进入此次 PDF。

## 系列阅读版式

默认 `standard` 为 A5、正文 11pt，采用黑、白和中性灰。`mobile` 为 90×160mm 的可选实验配置，只有明确选择才生成；每次不默认交付双版。两种配置共用语义正文和图片身份，分别保留导出号与检查结果。

| 部位 | 标准版要求 | 手机版要求 |
|---|---|---|
| 页面 | A5，上下18mm、左右16mm，单页连续阅读，不为凑奇偶章首制造空白页 | 90×160mm，上9mm、下12mm、左右7mm，页脚始终在纸张内 |
| 正文 | 11pt，段落行间补充间距0.68em，段距1.15em；长段和中英混排均须可读 | 11.5pt，同样保留行距；不能通过持续缩字容纳宽元素 |
| 代码/表格 | 代码8.6pt、表格9pt，允许跨页 | 代码9pt、表格9.5pt，宽元素需另外核对 |
| 层级 | 封面、版本来源页、精简目录、章首页、普通正文分工明确 | 保留相同层级，省去非必要页眉和装饰 |
| 导航 | 纸面目录默认仅一级章/主要任务；细层级由 PDF 书签承担 | 同样精简，不把全部小节印成数十页目录 |
| 单篇教程 | 使用简化标题页和版本来源信息；短篇可省去纸面目录 | 同样简化，不能机械套用整书扉页与章首页 |
| 颜色 | 文字、链接、代码、表格、提示均使用黑白灰 | 与标准版一致 |

以上数值为 `series-pdf-v1.1` 默认值，统一由系列模板定义；配置与模板SHA-256一起进入导出记录。一级标题标准版21pt、手机版19pt；二级15pt/14pt，三级12pt，四级11.5pt。书级确需覆盖时记录理由；先用难排样章核对，再用于整书。正文不得散布与某一纸张绑定的手工分页指令。修复应优先放在模板或语义适配层。

封面不显示正文页眉。标题不能孤立在页尾；正文页码、页眉和边注不得越出页面。空白或仅有横线的页面进入复核名单，逐项判断原因，不能按字符数自动删除图片页。来源页至少说明书名、作者或署名信息、正文版本、导出号、导出日期、来源 C 和阅读配置；缺失信息不得编造。

## 中文、代码与表格

字体必须覆盖实际中文、英文、标点和符号。正文、标题和代码字体分别声明、预检和登记，记录可取得的实际字体文件与 SHA-256；无法取得的项目如实标为未知，不以字体家族名称冒充文件锁定。缺字、意外替换和未嵌入字体需要处理或明确记录，不能悄悄换字体后仍宣称分页相同。

代码、命令、路径、配置与提示词保留可搜索、可复制的文本。长逻辑行需要视觉折行，保留缩进；多页代码允许跨页。不得用截图替代代码，不裁右边，不删除内容，不插入零宽字符或会改变命令语义的续行符。源代码的逻辑行不能为版宽被改写；PDF阅读器复制时仍可能带入视觉换行，必须实际抽查。出现该情况如实记录并提供绑定此次导出的原始代码，不能由源文本正确推断PDF复制已通过。

长表在行与行之间跨页，并重复语义表头；默认不把同一行拆成上下两页。单行内容已长于一页时，应重新组织为条目或拆分列/表，并保留信息，不通过持续缩字勉强容纳。宽表优先调整列宽与内容组织；仍放不下时按语义拆分或明确采用独立版面，不删列、不裁切、不把整表缩成不可读文字。表格字号与缩放有下限意识，是否可读以实际页面为准，不能只以“未越界”放行。

提示、引用、步骤和注释保持一致视觉语法。提示框跨页时保留内容与顺序；不为完整保框而留下大段空白。提示不能只凭颜色区分含义。

## 图片与图注

统一遵守 [插图规范](illustrations.md)：采用 notebook-pen-v1 手绘图、黑白中性灰、不透明细方格纸。导出复用 C 中已采用图片的原始文件字节及审校身份，不重新生成、不替换成截图、不重采样后覆盖源图。PDF 内部编码或压缩不等于修改源文件，追溯仍绑定输入原文件摘要。

图片尽量靠近首次解释，默认按正文顺序排放。常规图片与短图注为同一不可拆的语义图组，和周围正文保留呼吸间距。已登记图中明确配对的“图：说明”合入图注；保留 FIG 身份、原图名和原说明，不把一般正文吞入图注。图注左对齐、9.5pt深灰，与图间隔7pt；不要留下独立图注页。保持完整画幅和比例，不能为适配窄页自动裁掉标签、箭头或关系。按最终版心核对图中文字，清晰度不能只由像素尺寸推断。

常规图在版心内保持比例：A5最大宽116mm、最大高110mm；手机版最大宽76mm、最大高80mm。先按宽度排，超高才按比例收小；浅宽图不预留固定高度空框。显式采用 contain，不裁切、不拉伸。上限只是防溢出措施，不能证明缩小后图字可读；图与正文解释是否同页仍须实际查看。

图中的关键标签要与实际版面的9—10pt参照字样比较，手写墨迹高度不能直接冒称字号。以最终输出宽度反推制作要求；原图像素多或DPI高都不等于字足够大。专页若版心宽度不变，也不会使图字变大。密图需要更宽的独立版面、总览与局部的重新构图，或把细节留在可选复制正文中；未经重新研究与审校不自动裁图、拆图或改写图内文字。手机版还须按约390px宽实看，不能只把A5图缩进窄版。

页面保持白色；方格纸只在原图内部出现。提示保留细竖线，浅灰底主要留给代码；图外不叠加阴影、圆角卡片、额外边框或整页方格纹理。每页的主要视觉重点由内容决定，不为“好看”机械加图。

`figure_appendix: true` 可保留大图附录及双向跳转；默认不要求每份教程附加大图。附录用于放大查看，正文仍须读懂关键关系。正文图不可读时先改布局或重新研究总览/局部方案，不能以“附录可放大”为通过依据。

## 可追溯构建

每次导出记录以下不同输入，不把它们合并成一个“版本”：

- 正文：C 的完整提交、正文版本、章节清单、语言及书级配置。
- 排版：实际调用的工具文件和系列模板摘要、工具版本、阅读配置及全部生效参数；当前工具不必等于 C 中的工具，但必须明示。
- 资源：实际采用图的身份和原文件摘要，所用字体及可取得的字体文件摘要。
- 产物：导出号、日期、文件名、PDF SHA-256、完整命令/日志、机器检查和视觉复核状态。

独立书仓使用随书的工具、模板与规则快照，不隐式读取私有总控的最新文件。更新快照先比较已有定制，不覆盖单书已经采用的代码折行、图附录等能力。相同输入目标是能解释、能重建和能回归；未验证时不承诺跨操作系统逐字节相同。

工具非零退出、必要输入缺失或 PDF 无效均算失败。保留本次 diagnostics、参数和日志，不吞警告或失败码，不借用旧 PDF 冒充新结果。已有导出编号不覆盖；修复后用新的导出号，失败记录与旧交付文件保持原状。

## 验收与公开

机器检查和视觉复核分别记录。构建成功只代表产生文件；`pdf-check` 通过只代表其报告覆盖的机械项目通过。未知、跳过、依赖缺失和未查看的范围都要保留，不自动填写视觉通过或 PDF/UA 合格。

| 检查层 | 必查内容 | 结论边界 |
|---|---|---|
| 输入与结构 | 章节/图身份及顺序完整，来源/输出摘要绑定，PDF 可打开 | 不证明正文事实或页面可读 |
| 机械 | 页尺寸、文字边界、链接、字体信息与空白候选，以实际报告为准；书签树另行核对 | 边界扫描可能有误报与漏报，需要回看问题页 |
| 视觉 | 全书页面巡检；封面、来源页、目录、章首、跨页代码/长表、全部图片和候选问题页重点查看 | 缩略图总览不能替代图中文字和复杂页的足尺检查 |
| 使用 | 搜索、选字、中文与长命令复制、目录/书签/跨章及附录跳转 | 自动检测到链接存在不等于到达正确内容 |
| 阅读环境 | 手机版按约390px页面宽检查；实际阅读器/手机、读屏和目标读者试读按真实范围记录 | 未实测不得写“手机阅读已通过”或“无障碍已通过” |

同一引擎可完成编辑和视觉复核；另一引擎交叉审仅在作者明确要求时进行。检查记录绑定此次 PDF SHA-256、profile、审阅者、日期、实际范围、发现问题和结论；任何 PDF 字节变化都需要重新绑定检查，不能沿用旧文件的通过结论。

公开继续遵守 [发布规范](publishing.md)。仅本地导出不创建远端发行。准备公开附件时仍核对 C、PDF 字节与 `export.json`，要求真实视觉通过；另需满足正文的编辑、事实、操作和语言等公开条件。延后 PDF 使用独立导出版，标签指向原 C，不抢正文 latest。

## 技术参考与采用边界

参数化书籍配置、字体路径与可访问性信息组织参考 [Quarto＋Typst](https://quarto.org/docs/output-formats/typst.html)；中文混排、[跨页表格](https://typst.app/docs/guides/tables/)和[可访问性](https://typst.app/docs/guides/accessibility/)以 Typst 官方文档为参考。保留现有 Pandoc＋Typst，不因参考另一工具便增加第二套默认构建器。

Tagged PDF、书签和文本可抽取分别是能力，不等于 PDF/UA 合格。模板、字体、引擎和内容的许可分别登记，不能用工具开源推断资源均可随书分发。字体锁定、可访问性验证和手机实测以本次实际完成的范围报告。


## 阅读设计依据与当前验证

A5的116mm版心配11pt正文，约为每行30个全角字；参考[W3C中文排版需求草案](https://www.w3.org/TR/clreq/)的书籍行长讨论，本版不靠缩字增加容量。中文与技术字符串混排使用自然左对齐，是本项目的试排取舍，不宣称等同于传统中文两端对齐。Typst的[leading](https://typst.app/docs/reference/model/par/#parameters-leading)指行边缘间距，0.68em不能直接称为1.68倍行高；应按实际字体量基线。正文使用语言相符的引号，代码块保留原始ASCII引号。

图文就近、图注同页参考[NC State图表指南](https://grad.ncsu.edu/students/etd/etd-guide/tables-figures/)；比例与contain行为按[Typst image](https://typst.app/docs/reference/visualize/image/#parameters-fit)，图组及表格分页按[Typst figure](https://typst.app/docs/reference/model/figure/)。具体字号、留白、灰度和高度上限是本项目的设计选择，仍需样章和整书验证。

2026-09-26已用Claude Code固定提交中的三个真实片段及FIG-006/010/005制作A5局部对照。全42图只核对登记/尺寸/摘要，实看3图；局部校样不替代其余39图、真实手机或整书验收。私有记录见 private/mechanism/reviews/pdf-reading-design-2026-09-26/。

PDF适配仅将一级引用块开头的装饰性💡/⚠标记转成黑白“提示/注意”文字；已有【主线/支线】明文标签时去掉相应🎯/🌿装饰。代码围栏、引用内围栏、缩进代码和行内代码不改写，普通正文中的表情不参与此规则，遗留正文的其他彩色表情仍需在整书校样时核对。

## 彩色作者头像（2026-09-26）

作者确认PDF也使用原色头像，不采用灰度版。按[作者品牌规范](branding.md)，封面署名标准版22mm／窄版16mm；正文页眉左侧8mm头像与姓名，右侧书名。启用头像时正文上边距标准版20mm、窄版18mm；封面、来源与目录不重复页眉。此条是作者照片的明确例外，文字和教学插图保持原规则。素材取自固定正文提交，摘要进入导出回执。
