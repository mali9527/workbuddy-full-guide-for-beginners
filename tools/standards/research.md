# 全项目信息搜索与采集规范 · 1.0

采用日期：2026-10-03。适用于 AI教程工程现有及后续图书、独立教程、候选选题和运营研究。机制负责取得、记录和复用材料；不自动启动候选作品、写正文或发布。各书已有更具体的采用与原创要求继续生效。

## 先有材料，再给判断

经验性建议和外部案例必须关联已读的真人分享、经验帖或具体公开案例。产品功能、价格、权限、政策等可核对事实，按对应官方原页核实；不为每个官方事实强行找一个网友故事。使用经验不能取代产品事实，官方宣称也不能冒充独立使用体验。

AI 可设计检索、整理材料、比较与写作，不能制造经历、引用或访问结果。只读到标题、摘要、截图链接或搜索片段，登记为线索；影响采用的段落必须回读。研究没有完成时保留问题，不先写结论再补链接。

区分本人自述、机构案例、官方示例、转述、品牌合作和 AI 综合回答。记录原始发布者、过程、结果、失败和后续；账号自述不等于身份及经历已全部独立核实。推广内容可作线索，不作为购买推荐的唯一依据。转载同一来源不能按多份独立证据计数；点赞和搜索排名不能当正确率。

## 统一获取流程

先明确作品、场景、待回答问题和采用位置 → 查项目已有资料 → 搜原始材料及反例 → 读关键原文与必要媒体 → 登记阅读覆盖 → 提取说法 → 核对事实 → 作者选择采用、暂缓或淘汰。

一般互联网搜索和网页读取统一用内置 WebSearch/WebFetch。知乎、小红书等平台的已授权只读获取可用已验证的官方接口或 OpenCLI 等适配器；它们是特定平台获取入口，不替代通用 Web 搜索。登录、配置和平台权限沿已有授权处理，遇实际限制记录原因，不绕过安全策略。新闻联播任务继续走作者已授权的全局共享技能和资料库，不在此另建一份原文库。

选取支持、失败与不同条件下的材料；先用小批量判断相关性和独立性，再按问题补充。停止条件是关键问题有据可查、冲突已处理或明确暂缓，不是抓满任意条数。资料不够不等于网站工具坏了，访问失败也不等于该建议没有现实依据。

## 来源与采用分开

总控共享库保存来源记录和历史获取回执，各书保存对这些材料的判断。来源记录至少包括：

- 规范链接与原帖身份、标题、作者或机构、发表日期（未知保留空）、真实读取日期。
- 获取方式、平台、来源性质、阅读层次与定位、正文/图片/视频/评论实际覆盖。
- 自己的摘要、必要短摘录、商业关系、源头归属、未确认部分与使用条件。
- 固定来源 ID、记录修订号、记录摘要；重新读取或修正时添加新修订，不静默覆盖旧记录。

本书采用记录至少包括问题或说法、固定来源版本、相关原文位置、判断、条件、采用位置与当前状态。事实只在既有 facts.yaml 维护，单元引用只在 book.yaml 维护；有写作核验机制或既有来源库的作品，沿其原位置登记来源 ID/版本，不另造一份事实或通过状态。新研究包可用统一 collection.json 模板。共享来源更新不自动改变旧正文。

复用前核对问题相关性、日期、产品/地区/设备等条件。同一源多网址要核对源头后合并，不能粗暴删除全部 URL 查询参数造成不同文章碰撞。删帖、过时或新反例标在新记录并反查使用它的作品，形成修订任务；旧引用仍指向原有记录。

原始访问链接可能含平台访问参数，放不入版本库的本地临时区；规范链接、摘要与定位进入共享库。账号 Cookie、Access Secret、浏览器状态和无关个人资料不入库。不以信息收集为名复制整站或公开第三方全文、图片；工具代码许可不代替内容使用许可。

## 平台能力要有真实状态

文档宣称、软件安装、本地服务、浏览器连接、登录可用、搜索、详情、评论、媒体读取分别记录。至少完成一次“搜索 → 实际返回的原帖 → 评论或明确零评论 → 来源登记”才可说该平台文本采集链已跑通；图片与视频另验。工具 help 存在、服务启动、命令退出码 0 都不能代替业务成功。

每份回执有日期、工具版本、平台、查询词、实际条数、访问覆盖和错误类型。登录失败、验证码、限流、删除、解析缺字段与真实零结果区分。历史成功不能保证现在可用；环境、版本或站点改变时按需复验。新任务先看现有回执，不无故重复部署或升级。

## 作品适配与写作

所有作品共用以上能力。《人生的捷径》另要求每条正式建议有经验或具体案例；Muse 的典型案例还需按其多方认可规则；Codex 保留独立原创和既有写前学习提要，不能借共享库绕过本书对个人独特案例的限制。其他书以本书已采用规则判定。

后台研究记录完整，正文由作者明确给判断，引用与经验归属清楚。不会改变行动的核验细节不堆进正文；必要条件直接讲清。作者口吻不等于作者亲历，文风按各书约定，不把一种题材的写法强加给所有作品。

## 独立运行与验收

总控入口为 research-collect 技能；研究工具是私有生产助手，不成为公开书仓 check/build 的必需依赖。独立书仓和模板保存本规范固定快照，研究时可在本书既有私有记录中使用同等字段；不得隐式读取总控最新规则或把私有库搬进公开仓。

程序只检查字段、记录完整性和引用门槛，不判断事实真假、不鉴定真人身份、不替代阅读、操作或试读。历史资料逐项采用时补齐，不把未迁移记录伪造为已审；没有全量导入不表示既有书稿失效。具体平台状态与后续待办以带日期的真实回执为准。
