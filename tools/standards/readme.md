# 读者入口规范 · 0.1.0

书仓 README 面向当前读者：顶部说明适合谁、能做什么、当前模型／功能与怎么开始；中部按问题选章及可点击目录；底部为必要范围、许可、反馈和系列入口。真实的当前更新月份可突出，Star 提示说明收藏后的查阅用途。作者生产资料不占据阅读主线，私有报告不链接出去。

受管区使用 `<!-- studio:toc -->` / `<!-- /studio:toc -->` 与 `<!-- studio:release -->` / `<!-- /studio:release -->`；单元导航使用 `<!-- studio:nav -->` / `<!-- /studio:nav -->`。区外人工文字保留。

当前维护稿与固定里程碑分开；正文版本与 PDF 源版本分开。首页不推广过时版本、旧版读者分流或历史 PDF，相关真实历史保留在详情或记录页。没有成功公开的下载地址不提前生成。各语言说明实际完成范围，不把导览或落后译本称为全语言同步。

目录唯一来自 book.yaml，图数/章数可计算，不另写一份脚本清单。仅生成导航不修改正文核验状态。

当期模型关键词必须有真实正文支撑，紧接读者问题或任务收益；核对日期对应实际范围，不能仅因排版调整刷新。简介可用少量当前模型词，书名与长期封面保持稳定。独立书仓采用本规范即可检查本书首页，不依赖私有总控。
