## 这本书能帮你做什么

|日常工作|学会的AI工作习惯|
|---|---|
|读一堆资料，尽快接手工作|带着问题找答案，区分事实、推断与待确认项|
|写通知、说明和工作文稿|先说清读者和用途，再逐步做成可用文件|
|合并表格、统计与分析数据|先统一口径，再核对异常和关键数字|
|写总结、做汇报|从证据提炼成果，围绕听众决定重点|
|分析问题、比较方案|把原因、假设和选择标准分开，提出可试的办法|
|整理消息、推进任务|分清决定和建议，把事项落实到责任与下一步|
|每周、每月重复同类工作|保存稳定方法，更换当期材料，检验第二次能否复用|

提效从减少重复整理、材料搬运、无效往返和整项重做开始。书中既讲怎么交代任务，也讲为什么这样做，以及结果不对时怎样改；不要求先配置所有扩展，不预设节省倍数。

## 怎么读

|部分|对应章节|读完后能做什么|
|---|---|---|
|第一部分：从零上手|第01—12章|从第一次打开软件，到提供材料、交代任务、检查和保存结果|
|第二部分：高效办公|第13—20章|通过七类独立实战学会方法，再用综合任务练习组合、变更和复用|

第一次使用，从[阅读指南](manuscript/reading-guide.md)开始，依次读到第10章；第11、12章认识扩展与持续工作，按需阅读。七类实战互相独立，可以挑一件本周要做的工作开始。第20章把多种方法连起来用，不要求用齐七种能力。开篇、选读指南和附录不占章号。
