# 练习：减少周报材料的反复催补

这些材料为教学原创虚构。你负责汇总同事每周提交的材料，希望减少来回追问。先读 `reader/01-工作要求.md`，第一轮只交给 WorkBuddy reader 目录中的01至03；做出方案后再加入04；小试之后才看05。

输入文件可以逐个作为附件交给 WorkBuddy，也可以第一轮只把01至03复制到练习文件夹并指定读取。04和05留在该任务读写范围之外，到了对应阶段再加入。不要让它一次读取整个材料包，也不要把参考答案作为分析材料。

- [工作要求](reader/01-工作要求.md)
- [六次提交与八条往来](reader/02-提交与往来.md)
- [现行提交表](reader/03-现行提交表.md)
- [条件变化](reader/04-条件变化.md)
- [两次小试反馈](reader/05-两次小试反馈.md)
- 做完再对照：[参考分析](参考分析.md)

本题没有唯一最优方案。可核对的是记录有没有算错、判断有没有证据、方案有没有超出限制。
