# W01：一场分享活动改期

全部为教材原创虚构材料。你要先完成一份给协作同事的通知，不需要连接真实聊天、报名表或任何公司系统。

起步只把以下三份材料复制到练习目录，作为WorkBuddy输入：

1. [事实材料](reader/01-事实材料.md)：已确认安排、旧通知和六条留言。
2. [读者与分工](reader/02-读者与分工.md)：默认读者以及谁做什么。
3. [写作要求](reader/03-写作要求.md)：本次要交出的结果。

初稿完成后再按章中进度加入[后续变化](reader/后续变化.md)的一个小节。迁移另用[访谈情况说明](reader/迁移-访谈情况说明.md)，可独立开展。

最后再看[作者参考通知与事实答案](author/参考通知与事实答案.md)。请不要把参考答案一同作为起步输入，否则难以判断工具是否真正从材料中找对信息。参考稿是一种写法，不是要求照抄的标准句式。
