# 接手资料汇总工作

这是一套作者原创虚构练习。材料中的工作项目不是 WorkBuddy 产品里的“项目”功能，不需要建立项目或接入企业账号。所有人物、安排和文件为练习而设。

## 最短路线

只把“首次接手”中的五份文件交给 WorkBuddy。你在2026年9月29日接手资料汇总，要弄清五个问题：收什么、交给谁、何时交、按哪个版本、哪些还没决定。最终只要一份接手说明，答案带文件名与有关段落，未确认的事项单列即可。交付前，自己解释一次新旧规则的适用范围。

不要一开始把“作者参考”一起提供给工具。那是独立核对答案，不是待总结材料。

## 后续选择

- 主案完成后加入“后续补充/2026-10-02_正式补充.txt”，只更新受影响的回答。
- 需要自己长期负责时，再做“深入练习/三个新情境.md”。先回答，后看作者答案。
- 想练习材料缺失，可另开任务，用“故障练习/缺页_现行说明.txt”替代完整现行说明，其他四份保持不变。不要同时引用完整文件或旧任务摘要。观察是否会把FAQ当成缺失正式条款的替代。
- 需要迁移时，使用“迁移练习”中的独立入职材料，按其规则回答问题，不照搬主案的判断条件。

无需制作额外卡片、来源账本或知识库。你可以在当前任务直接阅读，或保存一份接手说明。实际 WorkBuddy 输出尚未采集，作者参考是人工编写的核对依据。
