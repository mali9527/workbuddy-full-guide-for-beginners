# 综合实践：月度资料交付小结

原创虚构教学材料，不设共同公司。你负责整理若干办公资料，需要向接收人交一张核对与统计表、一页工作小结和简短的后续安排。用同一批事实连接数据分析、汇报和任务推进。

按以下顺序使用。第一轮单独准备练习文件夹，只放入本轮需要的三份材料；不要将整个C02目录作为工作空间或一次全部上传：

1. 第一轮只给[交付要求](01-交付要求.md)、[九月台账](02-九月交付台账.md)和[九月记录](03-九月工作记录.md)，完成草稿，标出待核日期。
2. 看过第一轮后，加入[九月更正](04-九月更正.md)，更新相互关联的成果。
3. 从已做好的流程中留下工作说明，新建任务，只给这份通用说明和[十月材料](05-十月材料.md)，验证是否能用新事实完成相同用途的工作。

[作者参考判断](参考判断.md)留到做完后核对，不能作为输入。旧的[三选一小练习](../C01/README.md)仍可用于单项热身，无需先完成。

文件使用Markdown，表格中的内容可以直接阅读或作为材料交给WorkBuddy。产出文件的格式按实际用途选择，本练习不要求制作幻灯片，不要求建立连接器或定时任务，也不需要真的向任何人发送。
