# 六个文件的整理与交付练习

所有内容为作者原创虚构材料。这里是每周例会资料，与前面“一次例会时间调整”是两个独立练习。主输入只有“原始材料”目录里的六个文本文件；本说明与作者答案不是整理对象。

## 开始

在“WorkBuddy练习”下建立“文件整理练习”，把整个“原始材料”复制到里面并改名为“操作副本”；同一层再建“整理输出”。材料包中的原始材料保留不动。WorkBuddy工作空间选择父目录“文件整理练习”，只读取其下操作副本，输出到其下整理输出。第08章按这个目录关系操作。

六个文件分布在四个子文件夹，其中两份都叫“例会安排.txt”，内容不同。“例会安排副本.txt”也不是可直接删除的重复件。先打开几份材料看清内容，再提出整理预览。

## 三次任务

1. 分类命名：先列出六个文件原路径、建议新路径、判断理由。按现行、历史、待确认分组；保留全部文件，不覆盖、不删除。你确认后才处理副本。文件名不要求与作者答案完全相同。
2. 比较两版正式安排：先比较正文的时间、地点、参加人员、材料、截止时间、提交方式和适用范围，再核对各自议程的三个时段。明确排除未确认讨论副本。
3. 形成说明：以“整理输出/例会安排变化说明”为目标，制作一份可编辑的短说明。选自己能打开的格式，检查后修改标题、另存确认版并重新打开。

## 变化练习

第一次只比较两版正文；结果完成后追加“请补上议程时段的变化，其他正确内容保留”。这是补充范围，不意味着第一次结果一定错。

运行中停止为选做，只有任务仍在运行才练习；已完成不必重跑来制造停止。

第二次让工具制作说明时，提供“作者参考/独立差异参考.md”也能单独进入第10章；此时它是明确标注的作者参考输入，不假装来自你的上一项工作。

## 核对

正文、正式附件和讨论建议必须区分；当前有效安排是周一14:00—14:30、305，不是文件日期更新的周二线上建议。整理后六份原内容均应保留，旧名相同也不能相互覆盖。作者答案放在“作者参考”目录，先练再看；未获得 WorkBuddy 实际执行结果。
