# 练习：把个人周报做成可以重复使用的工作方法

本例独立于基础篇周报。所有材料原创虚构。把固定说明和某一期资料交给 WorkBuddy；第二次新建任务，交同一说明与下一期资料。第三期用来观察缺少证据时会不会仍然强行写“完成”。

- [可修改的工作说明](每周工作说明.md)
- [第一期](第一期.md)：2026年9月14日至18日，六条记录与三项旧事项。
- [第二期](第二期.md)：2026年9月21日至25日，七条记录。
- [第三期](第三期.md)：2026年9月28日至10月2日，七条记录。
- 第三期写出草稿后才加入：[第三期补充](第三期补充.md)。
- 做完再看：[参考判断](参考判断.md)。

第三期完成后可以修改一条记录再做一次，用“草稿”和“确认版”区分输出。所有自动发送、真实目录整理、定时执行都是可选扩展，不是练习要求。
