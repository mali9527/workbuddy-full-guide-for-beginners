# 综合练习：选一项工作，做两轮

三组原创虚构小材料彼此独立。只选一组开始，先使用第一轮，再加入第二轮。输出保持相同用途，观察是否能只修改受影响的部分。无需组合成公司项目。

|选择|第一轮|第二轮|够用的结果|
|---|---|---|---|
|读懂说明|[资料说明](A1-资料说明.md)|[补充说明](A2-补充说明.md)|给自己用的一页行动说明|
|写会议通知|[会议安排](B1-会议安排.md)|[安排变更](B2-安排变更.md)|一份同事看得懂的通知|
|看进度|[第一期进度](C1-第一期进度.md)|[第二期进度](C2-第二期进度.md)|一张状态表与两句判断|

完成后用[参考判断](参考判断.md)检查关键区别，不必模仿文字风格。
