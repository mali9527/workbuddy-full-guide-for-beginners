# F02：例会改期的三份材料

这是原创虚构练习，不需要了解任何公司的业务。你负责整理这一次部门例会的通知材料。输入只有三份：

- [现行说明](input/01-现行说明.txt)：已确认的本次安排。
- [旧通知](input/02-旧通知.txt)：核对旧安排，也可参考表达形式。
- [未确认备忘](input/03-未确认备忘.txt)：日期较新，但里面的建议未批准。

先在自己的“WorkBuddy练习”中建立“例会改期”文件夹，只把这三份输入复制进去。不要把作者参考稿也作为输入；练完再打开核对。

第05章先确认实际读取了什么、提取哪些安排已经改变，不必马上写通知。第06章沿用这份材料和同一个任务，写出能够让参加者采取行动的通知。

## 本次读者和用途

通知给原例会成员看，准备发到部门工作群；这里只起草，不替读者真正发送。
读者要知道这一次例会何时、何地召开，材料何时交、交给谁，以及是否影响以后例会。
语气简洁自然。正文约150—250字即可，不必写组织背景；可有一个短标题和少量要点。
不要把未确认的16:00开会、线上接入或会议链接写成正式安排。

## 第05章起步请求

> 请读取这三份文件，为这一次例会改期通知整理依据。先说实际读到了哪些文件、每份在这次任务中有什么用途，再指出已确认的三项变化、不变事项和仍未确认的建议。关键结论注明文件名和对应段落。不要现在起草通知，也不要用文件日期的先后代替确认状态。

## 第06章起步请求

> 请依据《01-现行说明.txt》给原例会成员写一份部门工作群通知。旧通知只用来核对变化和参考表达，未确认备忘里的建议不要采用。正文约150—250字，写清这一次会议的新时间、地点、材料期限和提交方式，提醒大家更新安排；保留“仅这一次调整、之后按原安排”的范围。只起草，不发送，不创建真实日历事项。

## 一次局部修改

> 请只压缩通知开头的背景说明，改成直接说明本次例会安排有调整。保留会议时间、地点、材料截止、提交方式，以及“仅这一次调整”的范围；其他内容不动。如果开头已经足够直接，就说明无需再压缩，不要为了改写增加新理由。

## 核对

练完查看[作者参考](reference/作者参考.md)。参考用于检查事实，不要求输出逐字相同。若当前环境没有读到某个文件，先补可读文本，不能把看见文件名当成已经读到正文。
