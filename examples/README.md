# 练习材料

全部为教学原创虚构材料。它们模拟常见办公工作，不共用一家公司背景。参考答案是作者依据输入整理的示范，未冒称 WorkBuddy 的实际输出。

要取得完整材料，在仓库首页点击 **Code → Download ZIP**，解压后打开 `examples` 文件夹，再按下表找到对应练习。只想先看内容，也可以直接点击下表链接；不需要安装 Git。

**只把当前这一轮需要的输入交给 WorkBuddy。** 默认将参考答案、后续变化和旧输出留在任务范围之外；只有练习明确要求作为输入时才加入，并注明用途。每个练习的说明会告诉你何时加入下一份材料。

文件夹名称中的字母与数字只用于辨认材料，不需要记忆。TXT和Markdown都是文字材料，可以打开后复制内容，也可以作为附件。P04提供六份Excel练习输入与后续文本；这些表是教学素材，不是已经运行验证的WorkBuddy结果。

开始时，把必要输入复制到自己新建的练习文件夹，原包保留。若不熟悉如何给材料，回看[第05章](../manuscript/materials.md)；若不清楚怎样找到和使用产物，回看[第10章](../manuscript/results.md)。
