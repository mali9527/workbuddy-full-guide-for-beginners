# 把三份表合起来，得到可信的数字

你收到三个区域的交付台账，需要知道本月原本应交付多少单、其中多少单按期完成。材料为原创虚构。这里的“交付单”就是一项有约定日期、需要登记完成情况的工作；无需先了解某家公司。

先做A。B在学会合并后逐条加入，C用来验证下个月能否复做，选做材料不影响主线起步。教材中的参考数字来自作者独立核算；你的工具产物仍需核对。

## A：先合并正常的三份表

复制下面三份文件到新的“8月交付练习”文件夹，WorkBuddy本次只使用这个文件夹。

- [东区台账](A首次合表/A_东区.xlsx)
- [中区台账](A首次合表/A_中区.xlsx)
- [西区台账](A首次合表/A_西区.xlsx)

三表同一结构，共20条，每个交付单在A包只出现一次。一行是一张交付单的一次状态登记。订单可能包含多张交付单，一个客户也可能有多个订单，因此订单号、客户编号不能直接当去重依据。来源行编号只为回查原材料。

这次的两项指标和条件由你明确提供：

- 统计期为2026年8月1日至31日；状态截至2026年9月5日18:00，北京时间。
- 按“原约定交付日”判断属于哪个月；不按实际完成月份归期。
- 计划数：原约定日在8月、截至点未取消的交付单数量。
- 按期数：上述计划中已经完成、实际交付日不晚于原约定日的数量。同一天完成算按期。按期率是按期数除以计划数。
- A包三地区已经全部提供。未完成的记录仍属于计划，不能只挑已完成的行来计算。

可以这样开始：

> 请读取这三份区域交付台账。统计2026年8月、截至9月5日18:00（北京时间）的计划交付数和按期交付数，按原约定交付日归期，未完成仍计入计划；同一天完成算按期。一张交付单算一个对象。先用DL-0001、DL-0004、DL-0002、DL-0003、DL-0017五条说明判断方法，保留来源，暂不扩展其他指标。

对照原表看这五条：提前、当天、延后、未完成、跨月完成分别怎么判。理解后再继续：

> 请按刚才确认的规则合并全部记录，生成一个可编辑的Excel工作簿，给出各区域及总计的计划数、按期数、按期率，保留可回查的明细、原文件名和来源行编号。另列需要继续跟进的未完成事项。不要改原文件，告诉我成果位置。用简短文字说明数字支持什么，原因不足的地方不要猜。

不必同时做图表或PPT。打开结果，回查几条关键记录，检查总计和区域数是否能对上。只看一个好看的百分比不够。

## B：每次只加一条变化

保留A成果副本，继续使用8月和同一截至时点。依次把B目录中的[B-01](B逐次变化/B-01.txt)到[B-08](B逐次变化/B-08.txt)单条文件复制进练习目录，每次处理后再放下一条；不要一开始提供全部八条。

> 这是新收到的一条登记。请在原来的统计规则和截至时点下更新结果，保留旧记录与来源，告诉我哪些结果改变、为什么。完全相同的业务副本不重复算；同一交付单的状态更新按登记时间处理。相同最新时间互相冲突时不要任选一条；字段缺失时说明哪些判断还能确定、哪些要核实。

遇到冲突或缺失，允许得到“暂不能确定”的结果。读者需要学会的是给出业务规则、让工具指出受影响的数字，然后补充真正缺少的信息。不要为得到一个完整百分比而删掉难处理的记录。

这里逐步练副本、状态更新、跨月完成、相同时刻冲突、取消、缺日期和后续更正。八次变化是教学用的小步练习，工作中不必永远一条条交给AI。

## C：换一个月，再做一次

另建“9月交付练习”文件夹，只复制以下三份文件。保留你已经确认的处理规则，更新月份与截至时间，得到同样用途的工作簿。

- [9月东区](C正常换期/C_东区_9月.xlsx)
- [9月中区](C正常换期/C_中区_9月.xlsx)
- [9月西区](C正常换期/C_西区_9月.xlsx)

统计期改为2026年9月1日至30日，状态截至10月3日18:00，北京时间；三地区资料齐全，共12条。本次不带入B的未解决问题。检查是否还残留8月文件、日期、固定数字或旧结论。第一次得到正确结果、下一次换材料仍然正确，是两件需要分别验证的事。

如果成果使用公式，改一条练习副本后检查关联数字是否重算；如果成果是已算好的固定数字，修改原材料后需重新执行，并替换输出。不要把一张有数字的表误认为会自动更新。
