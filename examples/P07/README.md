# P07：从四周记录写一页个人月度总结

材料全部为原创虚构。主角是普通员工，工作围绕资料维护和内部支持，不需要带团队或批准他人的工作。主线只交一页文字，演示和口头练讲按需选择。

起步材料：

- [任务说明](reader/00-任务说明.md)
- [第一周](reader/01-第一周记录.md)、[第二周](reader/02-第二周记录.md)、[第三周](reader/03-第三周记录.md)、[第四周](reader/04-第四周记录.md)
- [进度小表](reader/05-进度小表.md)
- [同事反馈](reader/06-同事反馈.md)
- [未完事项与分工](reader/07-未完事项与分工.md)

将这些材料的副本放到同一练习目录。首次不用[后续变化](reader/后续变化.md)，不要把[作者参考与判断依据](author/一页参考与判断依据.md)交给工具；完成自己的一页总结后再对照。

有新要求时，从后续变化中一次选一条。年度迁移使用[六份年度摘录](reader/迁移-年度六份摘录.md)，它是另一份独立小包。没有要求你同时制作年度长报告或五十份周报。
