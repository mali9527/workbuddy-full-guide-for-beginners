# 把八条记录整理成周报

这是原创虚构练习。只需读入[工作记录](input/工作记录.txt)，不用先学完全部基础章节。

1. 在电脑上新建“我的周报练习”文件夹，把工作记录复制进去。
2. 在WorkBuddy新建任务，使用这个练习文件夹；加入复制的工作记录。
3. 输入下面的请求，完成后找到实际文件，逐条对照原始记录。

> 请根据附件中的8条记录，整理一份给直属主管看的本周周报（9月21日至25日，状态截至9月25日18:00）。控制在一页，分为已完成、进行中、待人回应、下周计划。保留R01—R08编号方便核对，不补造日期、成果或承诺。请生成可编辑的Word文件，保存到本次练习文件夹，并告诉我文件名和位置。

检查重点：通知发出不等于培训已经举办；草稿不等于定稿；下周安排不算本周成果。对询问设备清单的那条笔记，没有具体日期也能写清等待状态，不用猜。

觉得这一句太长时，再提一次局部修改：

> 请只把“进行中”部分《资料提交说明》的进展压缩为一句，突出整份说明尚未提交审阅，保留共3节、前2节已有草稿、第3节未完成这些事实。其他事项、数字、日期和下周计划不动。另存修订文件，保留原文件，告诉我新文件的位置。

最后关闭并重新打开当前成果，确认内容、位置和可编辑性；做过另存修订时，再分别核对两版。把成功的要求保留下来即可，不必另填方法表。实际输出请依本书步骤核对，作者参考稿不代表工具必然生成同样结果。
