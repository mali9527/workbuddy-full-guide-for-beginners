# 第02章 安装与登录：准备好第一次使用

这一章完成安装、登录和练习材料准备。安装步骤只需阅读对应自己系统的段落；后面的登录回跳与工作位置说明，两种系统都需要看。

请先准备一台自己有权安装应用的电脑和可用网络。公司电脑如果由管理员统一管理，先按公司提供的安装方式操作。本章不用终端，也不需要自己配置编程环境。

## 从官方入口选择适合电脑的安装包

从[WorkBuddy 官网](https://www.workbuddy.cn/)下载对应系统的安装包。需要核对的不只是 Windows 或 Mac，还包括系统版本与处理器类型：应用支持你的系统，不一定表示每个安装包都适合这台电脑。

Windows 可以在系统“设置”中进入“系统”，再进入“关于”，查看 Windows 规格和设备规格。这里既能看到系统版本，也能看到处理器和系统类型。WorkBuddy 的 Windows 安装页列出 Windows 10 及以上、x64 环境；如果设备显示 ARM 架构，应再看当前下载页的适配说明，不要只因为同样叫 Windows 就任选安装包。[Windows 设备信息](https://support.microsoft.com/zh-cn/windows/experience/find-information-about-your-windows-device)、[WorkBuddy Windows 安装指南](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Win-Guide)

Mac 可以打开苹果菜单中的“关于本机”。显示 M 系列芯片时，对应 WorkBuddy 的 Mac ARM64 包；显示 Intel 处理器时，对应 Mac X64 包。官方安装页要求 macOS 12 及以上。这里的 ARM64、X64 是区分安装包适用硬件的名称，你只需把页面上的选项与本机信息对应，不用学习芯片原理。[Apple 芯片识别说明](https://support.apple.com/zh-cn/116943)、[WorkBuddy Mac 安装指南](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Mac-Guide)

安装要求可能随版本调整。下载时若官网说明与这里不同，以当前官方要求为准；不符合要求时，先解决设备适配问题，再继续。

## Windows：安装后从应用入口打开

打开下载好的安装包，按向导完成安装。没有单位要求时，沿用向导提供的位置即可。安装结束后，从开始菜单或桌面快捷方式打开 WorkBuddy。

若系统要求管理员凭据，而你没有安装权限，把应用名称、官方来源和提示交给管理员处理。这里需要解决的是安装权限，不是调整 WorkBuddy 里处理文件的权限；后者等开始任务时再设置。

## Mac：复制到“应用程序”后再打开

打开下载的 `.dmg` 安装文件，按官方说明将 WorkBuddy 拖入 Applications（“应用程序”）。等待复制完成，再从“应用程序”打开 WorkBuddy；以后也从这里启动，不必重新打开安装包。

首次打开出现提示时，先区分是在确认应用来源，还是报告无法运行。若无法运行，优先核对 ARM64／X64 包与本机芯片是否匹配、系统是否满足要求。不要用反复下载同一个包来代替这一步判断。

## 登录成功，要回到客户端再看一眼

官方文档常用“客户端”称呼安装在电脑上的 WorkBuddy 应用。登录从客户端发起，在浏览器中完成身份验证，再返回客户端。这个回跳过程，是首次使用时需要留意的一步。

点击应用中的登录入口，在打开的官方页面完成验证。个人练习使用自己可用的账号；组织统一登录则按组织安排。二维码、验证码等只在登录流程中使用，无需发给 AI。

网页显示登录完成后，切回 WorkBuddy。检查应用是否已经进入可开始任务的界面，账号信息是否符合预期。浏览器登录成功与客户端完成登录并不是同一件事；如果应用仍停在登录页，不要在多个窗口连续重复扫码。

先看看浏览器有没有等待你确认打开 WorkBuddy 的提示，再回到应用查看。仍无变化时，记录卡住的步骤与提示，重新从应用发起一次登录。公司网络或设备策略造成的拦截，应交给负责该环境的人处理，不必立即重装软件。

## 记住版本，再建立练习文件夹

应用会更新，教材和你看到的细节可能略有差异。官方导航说明把当前版本号列在左侧导航栏顶部，可以先在那里查看并记下号码。需要检查更新时，打开账号头像菜单，找到“检查更新”。记录的是本机显示的版本，不要把官网某条更新日志的号码当成已经安装的版本。[左侧导航栏](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Sidebar)、[账号菜单说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/File-Browser)

在自己习惯的位置建立“WorkBuddy练习”文件夹，再建一个“我的周报练习”子文件夹。先用随书材料，第四章会把工作记录和周报结果集中在这里。

这个位置以后会作为任务的**工作空间**：告诉 WorkBuddy 此次主要在哪个文件夹读取材料、保存成果。它不等于软件安装位置，也不等于“请处理这里所有文件”。选定位置后，仍要在任务里说清使用哪份材料、生成什么。下一章会结合界面说明。

如果应用已经登录、练习位置已经准备好，就可以继续。此时不需要添加外部服务，也不必更改高级设置。

## 卡住了

下载没完成，就先处理浏览器中的下载问题；安装包打不开，先核对系统与安装包；网页登录成功但应用没变化，先检查登录是否回到客户端。遇到提示时，保留原文和发生步骤，比只说“不能用”更便于找到原因。若系统不符合官方要求，应换用符合要求的环境，避免反复安装同一个不适用的包。
